# Chess Project Overview

## Текущий статус проекта

### Что уже реализовано

- Локальный Pygame-клиент с доской, отрисовкой фигур и выбором ходов.
- Шахматная логика работает:
  - начальная расстановка фигур
  - генерация ходов для пешек, коней, слонов, ладей, ферзя, короля
  - рокировка
  - en passant
  - превращение пешки (promotion)
  - проверка мат/пат и завершения игры
- Есть базовые классы:
  - `engine/board.py` — хранение доски, выполнение и отмена ходов
  - `engine/move_generator.py` — генерация псевдоходов и фильтрация легальных ходов
  - `engine/figures.py` — константы фигур, координатные утилиты
  - `client/game.py` — состояние игры, выбор клетки и выполнение ходов
  - `client/renderer.py` — рендеринг доски, фигур, подсветка ходов и меню
  - `client/main.py` — основной игровой цикл Pygame
- Есть заготовка под сетевую часть:
  - `client/network.py` — пустой класс-заглушка для клиента сети
  - `server/main.py`, `server/manager.py`, `server/models.py`, `server/room.py` — заготовки, но логики ещё нет
- Папка `stockfish/` пустая, интеграция со Stockfish ещё не реализована.

### Что сейчас отсутствует или частично реализовано

- Нет полноценного меню режима игры:
  - выбор `локальная игра` / `против бота` / `онлайн игра`
  - настройки звука/музыки
  - кнопки `сдаться`, `предложить ничью`, `отменить ход`, `перезапустить партию`
- Нет интерфейса для онлайн-режима:
  - нет подключения через WebSocket или HTTP
  - нет матчмейкинга, комнаты, логики ожидания второго игрока
- Нет интеграции со Stockfish:
  - не реализован режим против шахматного движка
  - нет выбора уровня или анализа хода
- Нет анимаций ходов и фоновой музыки.
- В текущем UI есть только одна кнопка `Играть`.

## Рекомендации по следующим шагам

### 1. UI и логика режимов игры

В клиенте нужно добавить новые кнопки и экраны:

- Главное меню с выбором режима:
  - `Играть локально`
  - `Против Stockfish`
  - `Онлайн`
  - `Настройки`
- Во время партии — панель управления:
  - `Сдаться`
  - `Предложить ничью`
  - `Перезапустить партию`
  - `Отменить ход` / `Назад` (опционально)
  - Индикатор текущего игрока и статуса партии
- Для онлайн-режима:
  - экран ожидания соперника
  - индикатор подключения
  - информация о цвете игрока (`Белые` / `Чёрные`)
  - блокировка ввода, когда ход не ваш

### 2. Реализация онлайн-игры через ngrok

Планы для серверной части:

- Реализовать FastAPI/WebSocket сервер в `server/main.py`
- Создать `room` и `manager` для матчмейкинга и комнаты на 2 игрока
- Определить протокол обмена сообщениями (ход, сдача, ничья, подключение/отключение)
- Организовать клиентский `NetworkClient` в `client/network.py`:
  - `connect(uri)`
  - `send_move(move)`
  - `send_resign()`
  - `send_draw_offer()`
  - `receive_game_event()`
- Использовать ngrok для проброса локального сервера в интернет, чтобы второй игрок мог подключаться извне.
- Важно: синхронизировать состояние доски и блокировать клики вне хода игрока.

### 3. Режим против Stockfish

Добавить реализацию против шахматного движка:

- В папке `stockfish/` хранить бинари или обёртку для Stockfish
- Внедрить `python-stockfish` или прямой запуск процесса UCI
- В `client/main.py`/`client/game.py` добавить выбор режима `Stockfish`
- Реализовать `AI move` после хода игрока
- Добавить настройку уровня сложности и времени на ход

### 4. Анимации и звук

UI можно улучшить следующим образом:

- Анимация перемещения фигуры по клеткам
- Плавная подсветка выбранного хода
- Звуковые эффекты:
  - ход фигуры
  - взятие
  - шах/мат
  - победа/ничья
- Фоновая музыка на главном экране и во время партии
- Кнопка `mute` в настройках

### 5. Тесты и качество

- Расширить тесты в `tests/` для:
  - корректности генерации ходов
  - проверки матовых/патовых позиций
  - работы рокировки и en passant
- Проверить, что `engine` продолжает правильно работать после добавления UI/онлайн-слоя
